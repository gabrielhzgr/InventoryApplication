# Inventory Application
## The Odin Project
Inventory demo app for a shoe store. 

It lets you keep track of shoe stock for differente shoe models, (e.g)
Nike blazer for men, has two variations one comes in brown, one in white, 
each one has different units in stock.

You can create, view, delete and update models and its stocks; the same
for brand and for demographic.

Built using the MVC pattern with express, pg (postgresql) for the db, 
express validator for the form validation and ejs for the views.

Live at: https://inventoryapplication-qpz1.onrender.com/
